# شعار مزايدة — المصدر

الملفات دي **نسخة طبق الأصل** من شعار العلامة في مشروع الويب
(`public/images/brand/` في الباك، اتضافت في الكوميت `a03e977`). محطوطة هنا
في `design/` مش `assets/` عشان مش كلها بتتشحن مع التطبيق — دي المصدر، وأصول
التطبيق بتتولّد منها.

| الملف | إيه ده |
|---|---|
| `logo-light.png` | الشعار الكامل (رمز + «مزايدة MAZAYADA») بكتابة كحلي — للأسطح الفاتحة |
| `logo-dark.png` | نفسه بكتابة بيضا — للأسطح الداكنة |
| `mark-light.png` | الرمز وحده بالكحلي |
| `mark-dark.png` | الرمز وحده بالأبيض |
| `icon-512.png` | أيقونة العلامة الجاهزة (لوحة كحلي بحواف دائرية) |

كحلي العلامة: `#01152E`.

## توليد أصول التطبيق

```bash
python3 tool/generate_logo_assets.py     # يولّد الـPNG في assets/logo/
dart run flutter_launcher_icons          # يولّد أيقونات Android و iOS
```

السكربت **مابيرسمش** حاجة — بيقصّ ويركّب ويحجّم الملفات اللي فوق بس، عشان
شكل التطبيق يفضل مطابق للويب من غير ما نعيد بناء الشعار بالكود.

الاستثناء الوحيد: `assets/logo/app_icon.png` بيتعمل **مربّع كامل معتم** بدل
الحواف الدائرية بتاعة `icon-512.png`، لأن iOS وAndroid بيطبّقوا قناع الحواف
بتاعهم — والسبب مشروح في السكربت.

## لو الشعار اتغيّر

استبدل الملفات هنا بالنسخة الجديدة من الباك وشغّل الأمرين فوق. مفيش ثوابت
شكل متكرّرة في الكود، فمفيش حاجة تانية تتعدّل — إلا لو كحلي العلامة اتغيّر،
ساعتها عدّل `BRAND_NAVY` في السكربت و`adaptive_icon_background` في
`pubspec.yaml` (لازم يفضلوا نفس القيمة).
