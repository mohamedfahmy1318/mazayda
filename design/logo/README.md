# شعار مزايدة — المصدر

الشعار **منقول من مشروع الويب**، حيث هو مكتوب SVG جوّه الـblade مباشرة مش
ملف صورة:

- `resources/views/layouts/citizen.blade.php` (رأس شاشات المواطن)
- `resources/views/layouts/auth.blade.php` (رأس شاشات الدخول)
- `public/favicon.svg` (أيقونة الموقع — نسخة 32×32 فيها لمسة ذهبية)

## الملفات هنا

| الملف | إيه ده |
|---|---|
| `logo.svg` | المصدر الرسمي — نفس مسارات الـSVG بتاعة الويب بالحرف |
| `favicon.svg` | نسخة الويب من أيقونة الموقع، للمرجعية |

## توليد أصول التطبيق

```bash
python3 tool/generate_logo_assets.py     # يولّد الـPNG في assets/logo/
dart run flutter_launcher_icons           # يولّد أيقونات Android و iOS
```

السكربت بيرسم نفس أشكال الـSVG بـPillow — فمش محتاجين حزمة SVG في التطبيق،
والنتيجة PNG حاد على كل المقاسات.

## لو الشعار اتغيّر

عدّل `logo.svg` هنا **وفي مشروع الويب** (المكانين)، وبعدين شغّل الأمرين فوق.
الثوابت (المسارات والألوان) متكرّرة في أول `tool/generate_logo_assets.py` —
لو غيّرت الشكل، غيّرها هناك كمان.
